Túnel de gestión

Esa IP es privada, así que la OLT está detrás de un router. Con un túnel el router marca hacia la plataforma y el equipo queda alcanzable sin dejarle SSH abierto ni guardar su contraseña. Si la OLT tiene IP pública no hace falta túnel. Se puede crear igual si prefiere no exponerla.

La red se suma a «{{ tunelElegido.nombre }}». Después de guardar, pegue el script en ese mismo router: agrega el acceso a la red nueva sin tocar las que ya tiene.

Si lo deja vacío se usa {{ redSugerida }}, deducida del host. Si ya hay un túnel que cubre esa red, se reutiliza en vez de crear otro.

Jump host (bastión SSH)

La plataforma abre una sesión SSH en este equipo y tuneliza cada consulta por ahí. Necesita SSH abierto y guarda su contraseña; el túnel de arriba evita las dos cosas.

Acceso directo: la plataforma se conecta a {{ form.host || 'la IP de la OLT' }} sin intermediarios. Si la OLT está en una red privada, lo que hace falta es el túnel de arriba, no un jump host.
