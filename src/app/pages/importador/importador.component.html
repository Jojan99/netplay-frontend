Qué día se le cobra a cada cliente

Los clientes se reparten en grupos de facturación. Cada grupo tiene un día del mes y ese día se le genera la factura a todos los del grupo.

{{ g.nombre || 'Grupo ' + g.grupo }} Día {{ g.billing_day }} {{ g.clientes || 0 }} clientes hoy

Todavía no tenés grupos de facturación. Creá al menos uno acá abajo: sin eso no se puede importar, porque cada cliente necesita saber qué día se le cobra.

 

Se pueden tener hasta 4 grupos, del día 1 al 30. En los meses más cortos (febrero) se factura el último día. Son los mismos de Configuración › Facturación.

¿Importar los clientes?

Se crean hasta {{ a.nuevos | number }} clientes nuevos y {{ opciones.existentes === 'omitir' ? 'se dejan como están' : 'se actualizan' }} {{ a.existentes | number }} que ya existen.

  • Estados: {{ opciones.estados.join(', ') }}.
  • Se crean {{ planesACrear }} planes, {{ planesSinValor }} sin valor mensual.
  • Se les cobra según su grupo ({{ opciones.grupo_modo === 'todos' ? textoGrupo(opciones.grupo) : 'repartido por ' + opciones.grupo_modo }}).
  • Todos quedan en el router {{ nombreRouter(opciones.router_todos) }}.
  • Se crean {{ saldoClientes | number }} facturas por el saldo, ${{ peso(saldoTotal) }} en total.

No se toca el router, no se le avisa a ningún cliente y no se genera ninguna otra factura.
